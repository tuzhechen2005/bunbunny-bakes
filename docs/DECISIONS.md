## 拷问后自定的细节

| # | 决策 | 理由 |

| D30 | 订单号显示为 `MMDD-NNN`（取货日期 + 当天第几单，例如 `1024-003`）；数据库里另存完整日期保证唯一 | 你在后台和微信里一眼能看出是哪天的单 |
| D31 | 专属链接用 32 字节加密随机数（base64url，43 个字符），明文存在数据库里，后台可以"复制链接" | 足够长，猜不中；店主需要能把链接重新发给顾客 |
| D32 | 顾客选日期时只显示"可选 / 已满 / 已截止"，不显示"名额较少" | 少一个阈值设置，也不暴露内部产能 |
