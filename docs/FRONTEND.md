# 前端改版 SPEC（v1，2026-10-23 定稿）

> 来源：2026-10-23 的前端 grilling（决策 D64–D72）。与其他文档冲突时以 `DECISIONS.md` 为准。
> 业务规则、金额计算、接口、数据全部不变；这次只改"看起来和用起来的感觉"。

## 1. 目标与非目标

**目标**：顾客端做成"杂志风 + 日系极简"的高级面包店网站，让人有下单欲望，并用两个招牌时刻展示技术水平（首页"今日出炉"麻绳、放进纸袋）。
**优先级**：下单顺畅 > 速度 > 惊艳。任何动效都不能挡住或拖慢下单。

**非目标**：后台全面改版（只换配色和字体）；3D 模型、WebGL、持续运行的 Canvas 背景；声音；新增业务功能；改动 `src/domain/**`、`src/server/**` 的行为。

## 4. 页面

### 4.1 首页
1. **顶部**：L3 标识 + 店名；接单状态一行。
2. **开场**：主标语用 React Bits **BlurText**（逐字从模糊浮现，只播一次），下面一行小字。
3. **「今日出炉」麻绳**（招牌）：一根横拉的麻绳，每款商品的**方形照片**像拍立得一样用小木夹子夹在绳上。
   - 左右滑动：绳子带着照片走；中间那张正对、最大，两边的稍微侧转（CSS 3D `rotateY`）并靠拢。
   - 照片像钟摆一样以夹子为支点轻晃，由滑动的加速度驱动，晃一下就稳（见 §5）。
   - 「今日出炉」四个字带 React Bits **ShinyText** 光泽，间隔若干秒划过一次。
   - 暂停供应的商品照片变灰，标签「暂停供应」，不能放进纸袋。
   - 点中间那张 → **取下来**（§4.2）；点两边的 → 先滑到中间。
4. **「全部面包」列表**：麻绳下方的简洁列表，每行照片缩略图、名称、简介、价格、数量加减。这是任何情况下都可用的保底下单路径（读屏、键盘、减少动态效果、旧手机）。
5. **你的纸袋**（底部固定）：牛皮纸袋图标 + 件数 + 金额（React Bits **CountUp** 滚到新数字）+「去结算」。接单关闭时保持现在的规则。
6. **页脚**：同现在（店主微信号按设置显示）。

### 4.2 商品详情「取下来」
- 共享元素过渡：照片从夹子上被取下，放大到屏幕上方；下面是名称、简介、单价和套餐价、数量加减、「放进纸袋」。
- 往下拉超过约 90 px、或点「挂回去」，照片沿原路飞回绳子，绳子轻轻晃一下。
- 详情页里也能左右切换到上一款 / 下一款。

### 4.3 放进纸袋
- 点「放进纸袋」（详情或列表）：商品小图沿弧线飞向底部纸袋（约 0.6 秒），纸袋接住后以底部为支点晃一下（钟摆），件数和金额更新。
- 安卓支持时 `navigator.vibrate(15)`；iPhone 无震动；无声音。
- 动画期间不阻塞任何点击，可以连续添加。

### 4.4 结算页
- 动效克制：只有淡入、数字变化、按压手感、日期卡片选中的细微动画。
- 换成新的颜色、字体、排版；流程、字段、校验、错误提示全部不变。

### 4.5 订单页
- 刚下单（`?new=1`）：一张**热敏小票**从顶部"打印"出来，逐行显示订单明细，最后"啪"地盖一个焦糖色「已预订」印章（参考 Hanger Club 的印章动画：从 2.2 倍斜着落下，约 0.26 秒落定，墨水般的 multiply 混合），结尾一句「面包已经在排队发酵啦！」。总时长约 1.2 秒，只播一次；随后是正常订单页（复制订单链接按钮在小票下方）。
- 再次打开订单页不播动画。

### 4.6 空状态与其他
- 空纸袋、404、加载失败：用 L3 标识 + 一句文案，安静克制。

### 4.7 电脑版（最后一个 task）
- 杂志跨页双栏：左侧麻绳，右侧列表和纸袋；结算页与订单页居中加宽。时间不够时先用"手机版居中"顶上。

## 5. 动效系统

- 动画库：**motion**（`motion/react`，用 `LazyMotion` + `domAnimation` 按需加载）。React Bits 只用 **BlurText、CountUp、ShinyText** 三个（D68）。
- 物理（从 Hanger Club 的 `src/motion/spring.ts`、`gesture.ts` 移植成 2D，`src/lib/motion/` 纯函数 + 单元测试）：
  - 位置弹簧：临界阻尼弹簧，固定 1/240 s 子步积分（60/120 Hz 表现一致）；绳子位置 1.7 Hz、阻尼比 0.9。
  - 钟摆：以夹子为支点，由支点加速度驱动，摆长等效 0.42 m，阻尼约 0.85 临界，驱动加速度上限 5 m/s²；一次用力甩动最多偏 10–15°，约 1 秒内静止。
  - 手势：移动 8 px 后锁定轴向；两端 iOS 式橡皮筋（最多 0.45 个位置）；按最后 100 ms 算速度；松手前停顿超过 80 ms 不算甩动；一次甩动最多移动 ±1 张。`touch-action` 只占用横向，不挡竖向滚动。
  - 不渲染时停止：全部静止后不再逐帧计算。
- **减少动态效果**（`prefers-reduced-motion`）：照片不晃、不飞、不 3D 旋转，改为淡入淡出；BlurText、ShinyText、CountUp 直接显示终态；小票直接出现。
- **自动降级**：运行时检测帧率，持续低于约 45 fps 时关闭钟摆和侧转，只保留平移。

## 6. 性能与兼容（验收标准）

1. 中端安卓 + 4G + 微信内置浏览器：首页 **2.5 秒内**可以点「放进纸袋」。
2. 首页首屏**改版新增**的 JS + CSS **≤ 60 KB**（压缩后，对比 main；框架本身约 203 KB 不计），标题字体子集 **≤ 125 KB**（D73）；照片懒加载、WebP、按屏幕尺寸给合适大小。CI 里加体积检查，超了就失败。
3. 动画在中端机上保持约 60 帧；掉帧自动降级（§5）。
4. 微信内置浏览器（iOS、安卓）和 Safari、Chrome 手机版都能正常下单。
5. 列表下单路径支持读屏软件和键盘；所有可点元素 ≥ 44 px；焦点可见。
6. 现有全部单元、数据库、e2e 测试保持通过；e2e 选择器跟着新结构更新，但覆盖的流程不减少。
7. 所有可见文字来自 `src/copy.ts`；顾客端不出现内部数据。
